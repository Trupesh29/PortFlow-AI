# Optimizer Module — PortFlow AI

This directory contains the mathematical optimization engine for PortFlow AI.

## Scope (Future Phase)
- **Algorithm:** Google OR-Tools CP-SAT discrete constraint programming.
- **Problem:** Joint vessel-to-berth and crane allocation over discrete 30-minute time slots.
- **Objective:** Minimize total vessel waiting time and maximize crane utilization.

> **Note:** No optimization solver logic is implemented in this skeleton phase.
