# IBM Bob Session Evidence

This folder is required by the IBM Bob Hackathon Guide for judging evidence.

For every relevant project task completed in IBM Bob IDE, export and add both:

1. The task history as a Markdown file.
2. A screenshot of the task session consumption summary.

Use paired, sequential names such as:

```text
01-database-foundation.md
01-database-foundation-usage.png
02-ml-pipeline.md
02-ml-pipeline-usage.png
```

Before publishing, inspect every export and remove credentials, API keys, secrets, and unrelated personal information. Do not fabricate Bob session evidence for work performed in another tool.
