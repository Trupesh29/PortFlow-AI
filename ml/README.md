# ML Module — PortFlow AI

This directory contains machine learning model training pipelines, feature engineering scripts, and inference services.

## Scope (Future Phase)
- **Congestion Predictor:** Rolling 72-hour window congestion probability classification / regression.
- **Waiting-Time Predictor:** Vessel queue waiting time prediction with explainability factors.
- **Model Artifacts:** Serialized Scikit-Learn / XGBoost `.joblib` models stored in `ml/artifacts/`.

> **Note:** No ML inference or training scripts are implemented in this skeleton phase.
